# 焼売蒸籠

焼売を蒸し上げる、火加減と湯量の管理シミュレーション。PC・スマホ両対応のブラウザゲーム。

## 構成

HTML / CSS / JavaScript のみの静的サイト（ビルド不要、そのままHP公開可能）。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造、SVGの共通グラデーション定義 |
| `style.css` | スタイル（レスポンシブ、スマホ最優先） |
| `script.js` | ゲームロジックと焼売の描画 |

## 遊び方

1. 蒸籠の空きをタップして、種を入れる
2. 火加減（止める / 弱火 / 中火 / 強火）で釜の温度を保つ
3. 各焼売を囲む輪の進み具合を見て、タップで取り出す
   - 金色の範囲: 見事な蒸し上がり（100点 + 連続ボーナス）
   - 金色より手前: 生焼け（0点・連続が途切れる）
   - 金色を過ぎる: 蒸しすぎ（30点）
   - 輪が一周: 焦げ付き（-50点）
4. 湯は蒸すほど減る。0になると空焚きで焦げやすくなるので「差し水」で補う
5. 制限時間と種の数は難易度で決まる。評価は 名人 / 熟練 / 一人前 / 見習い / 修行中

最高得点・音の設定・選択した難易度は `localStorage` に保存される。

## ローカルで動かす

`index.html` をブラウザで開くだけ。または:

```sh
python3 -m http.server 8000
```

## バランス調整

`script.js` 冒頭の `DIFFICULTIES` に 易しい / 普通 / 厳しい の3段階があり、制限時間・種の数・温度の追従・蒸し上がりの速さとそのばらつき（`cookSpeedMin` / `cookSpeedMax`）・金色の範囲・湯の減り方・評価基準を難易度ごとに設定できる。全難易度で共通の値は `BASE_CONFIG` にまとめてある。選択した難易度は `localStorage` に保存される。
